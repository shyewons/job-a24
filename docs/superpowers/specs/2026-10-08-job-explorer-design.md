# 일자리 탐색 동작 시안

사용자가 승인한 1차 서류 제출용 구성에 카드 뒤집기 요구를 반영한다.

- PDF의 네이비/코랄 카드와 세로 손잡이 구조를 유지한다.
- 손잡이를 아래로 당기면 지원을 한 번 기록하고 “플러팅을 날렸습니다”를 표시한다.
- 위로 밀면 카드가 뒤집힌다. 뒷면에서 급여, 거리, 업무, 정보부족, 기타 중 한 가지 이상을 클릭하여 선택한다.
- 선택 전에는 거절 완료를 누를 수 없다. 기타는 구체적 이유 입력도 필요하다.
- 취소하면 선택을 폐기하고 같은 공고 앞면으로 돌아온다.
- 지원 또는 거절 확정 시에만 다음 공고와 남은 공고 수를 갱신한다.
- 마지막 공고 후 완료 화면 및 다시 체험하기를 제공한다.
- 실제 지원 전송 없이 가상 공고 데이터를 사용하며 화면에 시연용임을 표시한다.
- 모바일 터치, 데스크톱 마우스, 클릭/키보드 대체 조작을 지원한다.

## 구조

외부 패키지 없이 열 수 있는 HTML/CSS/일반 JavaScript. 상태 로직은 `state.js`, 예시 공고는 `jobs.js`, UI와 제스처는 `app.js`로 분리한다. 공고 처리 결과는 현재 브라우저 탭 실행 중에만 유지한다. 새로고침은 새 시연을 시작한다.

## 검증

상태 전이 단위 테스트와 실제 브라우저 시연 테스트로 필수 사유, 취소, 중복 처리 방지, 마지막 카드, 재시작, 짧은 드래그, 터치 취소, 좁은 화면과 모션 감소 설정을 검증한다.
