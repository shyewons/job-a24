# 일자리 탐색 · 1차 제출용 작동 시안

`index.html`을 Edge 또는 Chrome으로 열면 바로 동작합니다. 설치나 빌드, 로그인은 필요하지 않습니다. 배포할 때에는 이 폴더의 HTML, CSS, JavaScript 및 assets를 함께 올려 주세요.

## 체험 순서

1. 흰색 손잡이를 아래로 당기면 아래쪽이 위로 넘어가며 카드 뒷면에 **플러팅을 날렸습니다**가 나옵니다. 약 2초 뒤 다음 화면으로 이동하며, **다음 공고 보기**를 눌러 바로 이동할 수도 있습니다.
2. 손잡이를 위로 밀면 위쪽이 아래로 넘어가며 거절 사유 뒷면이 나옵니다.
3. 뒷면에서 **급여 / 거리 / 업무 / 정보부족 / 기타**를 클릭하여 선택합니다. 복수 선택할 수 있습니다.
4. 사유가 없으면 완료할 수 없습니다. 기타 선택 시 구체적 사유도 입력해야 합니다.
5. **선택 완료 · 다음 공고**를 누르면 거절 기록을 남기고 다음 공고를 보여줍니다. **다시 볼게요**는 같은 공고 앞면으로 돌아갑니다.
6. 공고 6개를 모두 처리하면 요약과 **다시 체험하기**가 나옵니다.

카드 앞면이나 손잡이를 드래그할 수 있습니다. 손잡이의 위/아래 버튼은 클릭 대체 동작입니다. 키보드는 Tab/Enter, 손잡이에 포커스한 상태에서는 ↑/↓ 키를 사용할 수 있습니다.

새 공고가 나타나고 3초간 조작하지 않으면 손잡이가 아래로 8px씩 두 번 움직입니다. 공고당 한 번만 실행되며 지원 처리는 하지 않습니다. 사용자가 조작하거나 도움말을 열면 취소되고, 기기의 모션 감소 설정을 켜면 실행되지 않습니다.

헤더 중앙은 **일자리 탐색**, 오른쪽은 남은 공고 수입니다. 지원·거절 확정 시에만 수가 줄어듭니다. 하단 **나의 매칭**과 **피드백**은 이번 체험에서 남긴 기록을 보여 줍니다. 헤더 뒤로가기와 ?는 탐색 안내를 엽니다.

## 파일 구성

- `index.html`: 화면 구조 및 접근성
- `styles.css`: 색상, 크기, 반응형 배치, 카드 뒤집기 애니메이션
- `app.js`: 화면 갱신, 드래그/클릭, 피드백 선택
- `state.js`: 지원/거절/취소 상태 및 필수 사유 검증
- `jobs.js`: 가상 공고 6개
- `assets/office.jpg`: 사용자 제공 PDF에서 추출한 사무실 사진

색상과 손잡이 높이는 `styles.css`의 `:root` 변수에서 바꿀 수 있습니다. 카드 높이는 현재 보이는 면의 내용과 안쪽 여백에 따라 자동으로 정해집니다. 공고 내용은 `jobs.js`에서 수정합니다. HTML/CSS는 스페이스 4칸으로 들여쓰기합니다.

## 시안 범위

실제 기업 지원, 고용24 API, 로그인, 서버 저장, 기업 매칭은 연결되어 있지 않습니다. 체험 기록은 메모리에만 남으며 새로고침하면 초기화됩니다. 실제 공고나 실제 지원 완료로 제출하지 않도록 시연용임을 화면에 표시했습니다.

## 검증 실행

Node.js가 설치된 환경에서:

```powershell
node --test tests/state.test.cjs
node tests/browser.cjs
node tests/flip.cjs
node tests/card-layout.cjs
node tests/handle-hint.cjs
```

브라우저 테스트는 Playwright와 Edge가 필요합니다. 이 작업 환경의 번들 Playwright 경로가 기본값이며, 다른 환경에서는 `PLAYWRIGHT_PATH`에 Playwright 패키지의 절대 경로를 지정하세요.

검증 기록은 프로젝트의 `docs/superpowers/plans/2026-10-08-job-explorer.md`를 참고하세요. 실제 iOS Safari 기기 검증은 수행하지 않았습니다.
