# 잡아24

구직자가 공고를 탐색하고 지원 현황과 주간 이력서 피드백을 확인하는 웹 프로토타입입니다. HTML·CSS·JavaScript로 제작했으며, 데이터는 시연용입니다.

## 주요 화면

| 화면 | 파일 | 주요 기능 |
|---|---|---|
| 일자리 탐색 | `index.html` | 카드 지원·거절, 필수 거절 사유 선택, 공고 상세보기 |
| 나의 매칭 | `html/matching.html` | 상태별 필터, 정렬, 요청·면접 안내 확인 |
| 피드백 | `html/feedback.html` | 쿠폰 현황, 주간 보고서 목록, 지원 기업 목록 |
| 주간 이력서 피드백 | `html/feedback-report.html` | 지원 결과 도넛 차트, 사유별 집계, 공고별 피드백 |

## 실행

`prototype/index.html`을 브라우저에서 바로 열면 실행됩니다. 별도 설치나 빌드는 필요하지 않습니다.

로컬 서버로 확인하려면 `prototype` 폴더에서 실행합니다.

```sh
python -m http.server 4173
```

접속 주소: http://localhost:4173

## 수정 위치

- `css/styles.css`: 공통 색상·폰트·여백과 탐색·매칭 스타일
- `css/feedback.css`, `css/feedback-report.css`: 피드백 관련 스타일
- `js/jobs.js`: 탐색 공고 데이터
- `js/matching.js`: 매칭 예시 데이터와 필터·정렬
- `js/feedback.js`, `js/feedback-report.js`: 쿠폰·보고서 동작과 데이터

색상은 공통 `:root` 변수를 사용합니다. 기업명·본문은 **14px**, 공고명·제목은 **18px**, 보조 문구는 **12px**, 콘텐츠 좌우 여백은 **16px**입니다.

## 시연 범위

- 실제 지원 전송, 기업 요청, 이력서 분석, 서버 연동은 구현하지 않았습니다.
- 매칭 목록은 탐색 기록과 연동하지 않는 예시 공고 8건입니다.
- 탐색 기록과 쿠폰·보고서 열람 상태는 현재 탭의 `sessionStorage`에 저장됩니다.
- 열람한 보고서는 쿠폰 추가 차감 없이 다시 볼 수 있습니다.
